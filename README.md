# Gesture Synth · solo sito pubblicato

**Per suonare: [apri Gesture Synth](https://soldo07.github.io/gesture-synth-web/).**

Questo repository contiene soltanto i file compilati che servono a pubblicare
il sito gratuitamente. Non è il progetto su cui modificare il codice.

Il progetto principale è **[gesture-synth-sorgenti](https://github.com/Soldo07/gesture-synth-sorgenti)**,
privato e accessibile al proprietario. Lo sviluppo si fa lì; qui si aggiorna
soltanto la distribuzione. Credenziali, certificati, chat e impostazioni
personali non fanno parte del sito.
